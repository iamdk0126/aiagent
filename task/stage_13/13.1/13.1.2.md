## 1. 階段目標與職責邊界
本階段的目標是實現 `check_budget` 方法，用於檢查當前項目預算是否超出上限。如果超出則觸發熔斷機制，自動切換回 `FREE_LOCAL` 地端免費模型。此外，還需要實現異常處理和單元測試，以確保系統的穩定性和可靠性。

## 2. 與父階/爺爺階及全域註冊表之資料表與介面契約
本階段將使用 `budget_rules` 資料表來存儲單專案的預算規則。具體來說，`budget_rules` 資料表包含以下欄位：
- `project_id` (TEXT): 專案ID
- `max_shot_cost` (INTEGER): 最大單鏡預算
- `max_episode_cost` (INTEGER): 最大單集預算
- `max_project_cost` (INTEGER): 最大單專案預算
- `current_project_spent` (INTEGER): 目前專案已支出
- `auto_fallback_to_local` (INTEGER): 是否自動切換到本地免費模型

import unittest

class TestBudgetRule(unittest.TestCase):
    def test_check_budget_within_limit(self):
        budget_rule = BudgetRule("project1", 1000, 5000, 50000, 4000, 1)
        self.assertTrue(budget_rule.check_budget())

    def test_check_budget_exceeded(self):
        budget_rule = BudgetRule("project1", 1000, 5000, 50000, 6000, 1)
        with self.assertRaises(Exception):
            budget_rule.check_budget()
